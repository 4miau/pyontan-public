# Getting help with pyontan

pyontan is closed source and comes from **[pyontan.com/download](https://pyontan.com/download)**. This repo is its public page: the details, the docs and a place to report bugs. I'm the only developer and I read everything that comes in.

## Where to go

1. **[docs/troubleshooting.md](docs/troubleshooting.md)**: the common problems and what fixes them
2. **[The guides](https://pyontan.com/guides)**: a walkthrough for each feature, from installing to Study
3. **[docs/faq.md](docs/faq.md)**: the usual questions
4. **[Send feedback](https://pyontan.com/feedback)** from the website or the app (the account menu, or the tray menu)
5. **[Open an issue](../../issues)** here, if you'd rather use GitHub
6. **[Discord](https://discord.gg/Pz3gCFPejV)**: questions, ideas, and other people using pyontan

## What to put in a report

- What you did, and what happened instead
- Which part: the Windows app, Android, the website or the browser extension
- The version. In the Windows app it's at the top of the tray menu's Help
- A screenshot, if it's something you can see

## Asking for a feature

Ideas are welcome, as an issue or in Discord. The [roadmap](https://pyontan.com/roadmap) shows what's planned and what's being worked on.

## Security

Found a security problem? Please don't open a public issue. See [SECURITY.md](SECURITY.md).
